## TL;DR
Find all unique triplets that sum to zero. Sort the array, fix one element, and reduce the rest to a Two Sum problem solved with a converging two-pointer scan — carefully skipping duplicates at every level to keep triplets unique.

## Approaches
- **Sort + fix + two pointer** — sort ascending, loop `i` over each element, then two-pointer `left`/`right` over the remainder looking for `nums[left] + nums[right] == -nums[i]`. Skip duplicate values for `i`, `left`, and `right`. Time O(n²), space O(1) (excluding output).

## Best solution
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int size = nums.size();
        vector<vector<int>> res;

        sort(nums.begin(), nums.end());

        for (int i = 0; i < size - 2; ++i) {
            int left = i + 1, right = size - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {
                    res.push_back({nums[i], nums[left], nums[right]});

                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (right > left && nums[right] == nums[right - 1]) right--;

                    left++;
                    right--;
                } else if (sum > 0) right--;
                else left++;
            }

            while (i < (size - 2) && nums[i] == nums[i + 1]) i++;
        }

        return res;
    }
};
```
Optimal because sorting lets a single two-pointer pass replace the inner O(n²) pair search, so total work is O(n²) instead of the O(n³) brute force.

## Notes
- The note stresses that the **"after repetitions ignored, move ahead" flow is VERY important** — you skip the run of duplicates first, then take one more step to land on the next distinct value.
- The note recommends NeetCode's explanation as the simplest walkthrough.
- Two dedup loops are needed inside (for `left` and `right`) plus one outside (for `i`).
