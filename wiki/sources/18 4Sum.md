## TL;DR
Find all unique quadruplets that sum to a target. A direct extension of 3Sum: sort, fix two elements with nested loops, and two-pointer the remaining pair — deduplicating at every one of the four levels.

## Approaches
- **Sort + two fixed loops + two pointer** — sort ascending, outer loops `i` and `j` fix the first two elements, then `left`/`right` converge on the rest. Skip duplicate values for all four indices. Accumulate the sum in a `long` to avoid overflow. Time O(n³), space O(1).

## Best solution
```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int size = nums.size();
        vector<vector<int>> res;

        sort(nums.begin(), nums.end());

        for (int i = 0; i < size - 3; ++i) {
            for (int j = i + 1; j < size - 2; ++j) {
                int left = j + 1, right = size - 1;

                while (left < right) {
                    long sum = (long)nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum == target) {
                        res.push_back({nums[i], nums[j], nums[left], nums[right]});

                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (right > left && nums[right] == nums[right - 1]) right--;

                        left++;
                        right--;
                    } else if (sum > target) right--;
                    else left++;
                }

                while (j < size - 2 && nums[j] == nums[j + 1]) j++;
            }

            while (i < size - 3 && nums[i] == nums[i + 1]) i++;
        }

        return res;
    }
};
```
Optimal for the general k-Sum reduction: each additional fixed element adds one nested loop, so 4Sum is O(n³) with the two-pointer inner pass replacing an O(n²) brute search.

## Notes
- The `(long)` cast on the first operand promotes the whole sum, guarding against `int` overflow when four large values are added.
- Dedup is required at all four levels — two inner (`left`, `right`) plus two outer (`i`, `j`).
- The note points to NeetCode for the simpler explanation and frames the whole thing as "extension to 3 Sum".
