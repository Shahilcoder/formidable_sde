# 50. Pow(x, n)

Time Complexity: O(log(n))

Space Complexity: O(1)

https://algo.monster/liteproblems/50

### **Quick Power (Binary Exponentiation) Algorithm:**

Binary exponentiation is an optimized way to calculate **aⁿ** using **divide and conquer**. Instead of multiplying `a` repeatedly `n` times, we break it down efficiently:

- If n **is even**:

$$
a^n=(a^{n/2})^2
$$

- If **n is odd**:

$$
a^n=a×(a^{(n-1)/2})^2
$$

By repeatedly **halving** `n` and **squaring** `a`, we reduce the number of multiplications from **O(n) to O(log n)**.

For negative `n`, return `1 / qpow(a, -n)`, since $a^{-n}=1/a^n$.

This reduces exponentiation from **O(n) → O(log n)**, making it much faster!

Recursion way (makes more sense)

```cpp
class Solution {
public:
    double qPow(double base, unsigned int exponent) {
		    // Anything to the power 0 is 1
        if (exponent == 0) return 1.0;

        // exponent be odd or even... (exponent / 2) will be same here in C++.
        // head recursion
        double temp = qPow(base, exponent / 2);

        // check exponent is odd
        if (exponent & 1) return base * temp * temp;

        return temp * temp;
    }

    double myPow(double x, int n) {
        /* Quik power / Binary exponentiation algorithm */
        return n >= 0 ? qPow(x, n) : 1 / qPow(x, -(unsigned int)n);
    }
};
```

Iterative way

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        /* Quik power / Binary exponentiation algorithm */

        // lambda function qPow
        auto qPow = [] (double base, unsigned int exponent) {
            // start with 1 as anything to power 0 is 1.
            double result = 1.0;

            while (exponent > 0) {
                if (exponent & 1) { // bitwise &, to check if number is odd
                    result *= base;
                }

                base *= base;
                // (exponent / 2) and (exponent - 1) / 2 will be same here in C++.
                // divide exponent by 2, using right shift operation
                exponent >>= 1;
            }

            return result;
        };

        // Note: if n is negative we return 1 / result else just the result
        // unsigned int typecasting to avoid integer overflow when flipping negative value to postive value.
        return n >= 0 ? qPow(x, n) : 1 / qPow(x, -1 * (unsigned int)n);
    }
};
```
