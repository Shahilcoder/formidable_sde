# 45. Jump Game II

My Approach (well greedy):

Time Complexity: O(n) (checked from leetcode)

it can be 1n, 0.5n, 0.23n at the end that’s O(n).

Space Complexity: O(1)

Extension of Neetcode’s Jump 1 video.

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int size = nums.size();
        int goal = size - 1;
        int jumps = 0;

        int max_index = goal;
        while (goal > 0) {
            int i = max_index - 1;

            while (i >= 0) {
                if (i + nums[i] >= goal) {
                    max_index = min(i, max_index);
                }

                --i;
            }

            jumps++;
            goal = max_index;
        }

        return jumps;
    }
};
```
