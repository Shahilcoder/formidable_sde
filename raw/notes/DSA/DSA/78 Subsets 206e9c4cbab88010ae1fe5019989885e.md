# 78. Subsets

Time Complexity: O(n * 2^n)

Space Complexity: O(n * 2^n)

**Key technique:** for making power set of a array/set with `k` elements, you just take the power-set of the array/set with `k-1` elements, take copy of all those elements and append the `k`th element of the array/set to each element, and shove them all into that power-set, and voila you get power-set for array/set with `k` elements. Do the same recursively.

I have used head recursion so it goes from length `n` all the way to length 0, where it appends {}, empty set/array, so now the head recursion after going way down to 0 length now rebounds back. While it does that, I take the current subset and do the **Key Technique with it.**

```cpp
class Solution {
public:
    void appendSubsets(vector<vector<int>>& result, vector<int>& nums, int len) {
        if (len == 0) {
            result.push_back({});
            return;
        }

        appendSubsets(result, nums, len - 1);

        auto temp = result;

        for (auto i: temp) {
            i.push_back(nums[len - 1]);
            result.push_back(i);
        }
    }

    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;

        appendSubsets(result, nums, nums.size());

        return result;
    }
};
```

## Backtracking Approach:

Time Complexity: O(2^N)

Space Complexity: O(N)

**Recursive Backtracking.** (Good when you want to generate solutions, keyword: ALL)

- Make a decision
- Recursion on that decision
- Hit the base case
- Undo that decision

Imaginary Tree, doing **Depth First Search**.

![Screenshot 2025-06-15 at 11.37.35 AM.png](78%20Subsets/Screenshot_2025-06-15_at_11.37.35_AM.png)

In Simple English:

1. Don’t Pick the number → Go ahead.
2. keep doing the recursion → Hit the base condition?
3. Undo.
4. Now Pick the number → Go ahead.
5. Do doing the recursion → Hit the base condition?
6. Undo.
7. Back to Step 1.

```cpp
class Solution {
    vector<vector<int>> res;
    vector<int> sol;
    vector<int> payload;

public:
		// Depth first Search.
    void backtrack(int index) {
        // Base Case
        if (index == payload.size()) {
            res.push_back(sol);
            return;
        }

        // Decisions
        // Don't pick the number
        backtrack(index + 1);
        // Nothing to Undo...

        // Pick the number
        sol.push_back(payload[index]);
        backtrack(index + 1);

        // + Undo that decision
        sol.pop_back();
    }

    vector<vector<int>> subsets(vector<int>& nums) {
        res = {};
        sol = {};
        payload = nums;

        backtrack(0);

        return res;
    }
};
```
