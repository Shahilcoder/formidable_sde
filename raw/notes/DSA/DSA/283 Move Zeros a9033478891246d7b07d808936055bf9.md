# 283. Move Zeros

Use Bubble sort, for especially bubbling the 0s.

Time Complexity: O(n^2) average case

Space Complexity: O(1)

```cpp
class Solution {
public:
    void zeroBubbleSort(vector<int>& nums) {
        for (int i = nums.size() - 1; i > 0; --i) {
            for (int j = 0; j < i; ++j) {
                if (nums[j] == 0) {
                    swap(nums[j], nums[j+1]);
                }
            }
        }
    }

    void moveZeroes(vector<int>& nums) {
        zeroBubbleSort(nums);
    }
};
```

Using Two pointer (slow and fast) approach

Time Complexity: O(n)

Space Complexity: O(1)

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int len = nums.size();

        if (len == 1) return nums;

        int slow = 0;
        // keep fast = 0, thinking of keeping fast = 1 will fail
        // the test case: [1, 0]
        int fast = 0;

        while (fast < len) {
            if (nums[fast] != 0) nums[slow++] = nums[fast];

            fast++;
        }

        while (slow < len) nums[slow++] = 0;
    }
};
```
