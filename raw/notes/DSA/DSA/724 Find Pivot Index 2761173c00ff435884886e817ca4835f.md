# 724. Find Pivot Index

**Bruteforce:**

Find left sum and right sum excluding the current index at each traverse. (I used C++ STL accumulate here)

Time Complexity: O(n^2)

Space Complexity: O(1)

```cpp
class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        auto i = nums.begin();
        auto e = nums.end();

        while (i < e) {
		        // https://stackoverflow.com/questions/3221812/how-to-sum-up-elements-of-a-stdvector
            int left_sum = accumulate(nums.begin(), i, 0);
            int right_sum = accumulate(i + 1, e, 0);

            if (left_sum == right_sum) return i - nums.begin();
            
            i++;
        }

        return -1;
    }
};
```

**Prefix Sum A:**

Time Complexity: O(n)

Space Complexity: O(n)

```cpp
class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int size = nums.size();

        int *left = new int[size];
        int *right = new int[size];

        left[0] = nums[0];
        right[size - 1] = nums[size - 1];

        for (int i = 1; i<size; ++i) {
            left[i] = nums[i] + left[i-1];
            right[size - i - 1] = nums[size - i - 1] + right[size - i];
        }

        for (int i = 0; i<size; ++i) {
            if (left[i] == right[i]) return i;
        }

        delete [] left;
        delete [] right;

        return -1;
    }
};
```

**Prefix sum B:**

Time Complexity: O(n)

Space Complexity: O(n)

The question did say we consider that left edge → left sum = 0, right edge → right sum = 0, but you take left sum[0] = nums[0], and right sum[size-1] = nums[size - 1], warna prefix Sum kharab ho jata hai result ending element.

1. Find the prefixSum from left to right, store into leftSum array (left to right)
2. Find the prefixSum from right to left, store into rightSum array (right to left)
3. Rerun the loop from i = 0, reading from **left to right**, find the common index where both arrays’ elements are equal

```cpp
class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int size = nums.size();

        vector<int> leftSum(size, 0), rightSum(size, 0);

        leftSum[0] = nums[0];
        rightSum[size-1] = nums[size-1];
        for (int i=1; i<size; ++i) {
            leftSum[i] = leftSum[i-1] + nums[i];
            rightSum[size-i-1] = rightSum[size-i] + nums[size-i-1];
        }

        for (int i=0; i<size; ++i) {
            if (leftSum[i] == rightSum[i]) return i;
        }

        return -1;
    }
};
```

class Solution {

        }
